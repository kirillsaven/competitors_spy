# Roadmap

## v0.1 - Public OSS baseline

- public-safe docs
- reproducible local Docker setup
- YouTube tracking
- TikTok/Instagram provider abstraction
- Telegram scheduled reports
- CI and test baseline

## v0.2 - Provider hardening

- better provider rate-limit handling
- provider diagnostics page/command
- safer retries and backoff
- provider fixture library
- better offline development mode

## v0.3 - AI-assisted reports

- optional OpenAI-powered trend summarization
- no OpenAI key required for core functionality
- strict redaction before model calls
- deterministic fallback when no API key is present
- user-visible disclosure when AI summaries are enabled

## v0.4 - Maintainer automation

- AI-assisted issue triage
- PR review checklist generation
- release note drafting
- test gap suggestions
- security review prompts

## v1.0 - Stable OSS release

- documented extension API for providers
- stable deployment guide
- security review
- tagged releases
- mature contribution workflow
