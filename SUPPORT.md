# Support

Competitor Spy is self-hosted open source software, not a hosted SaaS support desk.

Use GitHub issues for:

- reproducible bugs;
- documentation gaps;
- feature requests;
- small contributor tasks.

Use GitHub Security Advisories for vulnerabilities:

https://github.com/kirillsaven/competitors_spy/security/advisories/new

Do not share secrets or private operational data in public issues, pull requests, screenshots, logs, or comments. This includes:

- `.env` files;
- API keys and bot tokens;
- database or Redis URLs;
- Telegram user IDs, chat IDs, and message IDs;
- private server names, IP addresses, paths, or deployment records;
- raw provider payloads copied from private accounts.

For troubleshooting, start with [docs/troubleshooting.md](./docs/troubleshooting.md) and include only redacted command output when opening a public issue.
